# ЛР0 — Карьев Данил Константинович, БИС-24-1

Сервис-счётчик из двух контейнеров: Flask и Redis.

## Запуск

```bash
docker compose up --build -d
curl http://localhost:8080
curl http://localhost:8080
```

Число посещений должно увеличиваться. Веб-приложение работает от пользователя `appuser`; порт Redis наружу не опубликован. Результаты проверки и ответы на вопросы находятся в [REPORT.md](REPORT.md).

Открытый SSH-ключ для сдачи: [PUBLIC_KEY.txt](PUBLIC_KEY.txt). Закрытый ключ в репозиторий не добавляется.
