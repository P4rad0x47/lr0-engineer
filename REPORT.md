## Ответы на вопросы

### Зачем запускать приложение от непривилегированного пользователя?

Если приложение взломают, процесс с правами `appuser` не сможет выполнять внутри контейнера действия, доступные `root`. Это уменьшает возможный ущерб, хотя не заменяет обновления, сетевые ограничения и другие меры защиты.

### Почему порт Redis не публикуется наружу?

Redis нужен только веб-приложению, которое обращается к нему по имени `redis` во внутренней сети Docker Compose. В этой лабораторной Redis работает без пароля, поэтому публикация его порта позволила бы посторонним читать или изменять счётчик.

### Чем открытый SSH-ключ отличается от закрытого?

Открытый ключ (`id_ed25519.pub`) можно передавать преподавателю и добавлять на сервер: по нему проверяется подпись. Закрытый ключ (`id_ed25519`) должен оставаться только у владельца; его нельзя отправлять в чат или добавлять в GitHub.
